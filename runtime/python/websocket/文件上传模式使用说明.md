# FunASR 文件上传模式使用说明

## 🚀 **概述**

这是一个全新的FunASR文件上传解决方案，**彻底解决了WebSocket逐块传输的慢速问题**！

### ✨ **主要优势**

- **🔥 极速上传**：HTTP文件上传，一次性传输完整文件
- **⚡ 高效处理**：服务端直接处理完整音频，无需重组
- **📊 实时进度**：WebSocket推送处理进度和结果
- **🎯 多模型支持**：Whisper、Paraformer、SenseVoice、混合模式
- **🎨 友好界面**：现代化Web界面，支持拖拽上传
- **🔧 灵活配置**：支持多种参数配置

## 📋 **架构对比**

### 原始WebSocket模式 ❌
```
文件 → 前端切片 → WebSocket逐块传输 → 服务端重组 → 处理
     (慢)        (很慢)            (慢)        (快)
```

### 新文件上传模式 ✅
```
文件 → HTTP一次性上传 → 服务端直接处理 → WebSocket推送结果
     (快)           (极快)          (实时)
```

## 🛠️ **安装依赖**

```bash
# 进入funasr环境
conda activate funasr

# 安装额外依赖
pip install aiohttp aiohttp-cors librosa websockets
```

## 🚀 **启动服务器**

### 方式1：使用启动脚本（推荐）

```bash
# 基本启动（默认Whisper base模型）
./start_upload_server.sh

# 指定模型类型和大小
./start_upload_server.sh whisper large-v3

# 指定端口
./start_upload_server.sh whisper base 8080 10095

# 使用GPU
./start_upload_server.sh whisper large-v3 8080 10095 cuda

# 使用FunASR模型
./start_upload_server.sh paraformer

# 混合模式（同时使用Whisper和FunASR）
./start_upload_server.sh hybrid large-v3
```

### 方式2：直接运行Python

```bash
# Whisper模式
python funasr_upload_server.py --model_type whisper --whisper_model base

# Paraformer模式
python funasr_upload_server.py --model_type paraformer

# 混合模式
python funasr_upload_server.py --model_type hybrid --whisper_model large-v3

# 自定义端口
python funasr_upload_server.py --http_port 8080 --port 10095
```

## 📱 **使用流程**

1. **选择文件**：
   - 点击"选择音频文件"按钮
   - 或直接拖拽文件到上传区域

2. **支持格式**：
   - MP3, WAV, M4A, AAC, FLAC, OGG

3. **上传处理**：
   - 点击"🚀 上传并识别"
   - 实时查看上传和处理进度

4. **查看结果**：
   - 自动显示识别文本
   - 包含时间戳信息
   - 支持多模型对比

## ⚙️ **配置参数说明**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--model_type` | whisper | 模型类型：whisper/paraformer/sensevoice/hybrid |
| `--whisper_model` | base | Whisper模型大小：tiny/base/small/medium/large/large-v3 |
| `--whisper_language` | auto | 识别语言：auto/zh/en/ja等 |
| `--http_port` | 8080 | HTTP上传服务端口 |
| `--port` | 10095 | WebSocket端口 |
| `--device` | cpu | 设备：cpu/cuda/mps |
| `--upload_dir` | ./uploads | 临时文件目录 |

## 🎯 **模型选择建议**

### Whisper模型
- **tiny**: 最快，准确率一般，适合实时场景
- **base**: 平衡选择，速度快，准确率较好
- **small**: 准确率更好，速度稍慢
- **medium**: 高准确率，适合离线处理
- **large/large-v3**: 最高准确率，适合专业场景

### FunASR模型
- **paraformer**: 中文优化，支持说话人识别
- **sensevoice**: 多语言支持，情感识别

### 混合模式
- 同时使用多个模型，结果对比
- 适合需要高准确率的场景

## 🔧 **API接口**

### HTTP上传接口
```
POST /upload
Content-Type: multipart/form-data

参数:
- audio_file: 音频文件

返回:
{
  "task_id": "uuid",
  "message": "文件上传成功，开始处理",
  "filename": "audio.mp3",
  "file_size": 7864320
}
```

### WebSocket接口
```javascript
// 注册任务
ws.send(JSON.stringify({
  type: 'register',
  task_id: 'uuid'
}));

// 接收进度更新
{
  "type": "progress",
  "task_id": "uuid",
  "status": "processing|completed|error",
  "progress": 50,
  "message": "处理中...",
  "results": {...}  // 完成时包含识别结果
}
```

## 🛡️ **安全说明**

- 上传的文件会在处理完成后自动删除
- 支持文件类型限制，防止恶意文件上传
- WebSocket连接有超时机制
- 临时文件使用UUID命名，避免冲突

## 🐛 **故障排除**

### 常见问题

1. **依赖缺失**
   ```bash
   pip install aiohttp aiohttp-cors librosa websockets
   ```

2. **端口占用**
   ```bash
   # 修改端口
   ./start_upload_server.sh whisper base 8081 10096
   ```

3. **模型加载失败**
   ```bash
   # 检查conda环境
   conda activate funasr
   # 重新安装模型
   pip install openai-whisper
   ```

4. **文件上传失败**
   - 检查文件格式是否支持
   - 确认文件大小不超过限制
   - 检查网络连接
